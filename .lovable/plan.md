
طلبك كبير ومتشعب، فاقترح تقسيمه على مراحل واضحة حتى يبقى المشروع متماسكاً وقابلاً للنمو.

## المرحلة 1 — الأساس (Backend + Auth + Header/Footer)

1. **تفعيل المصادقة** (Lovable Cloud) — تسجيل دخول راقٍ بنفس الهوية الذهبية الداكنة:
   - بريد + كلمة مرور + Google
   - صفحة `/auth` بتصميم سينمائي (خلفية متحركة + بطاقة زجاجية ذهبية)
   - جدول `profiles` (اسم، دور أسري: أب/أم/ابن/ابنة، تفضيلات)
   - جدول `user_roles` منفصل (admin/user) — لحماية لوحة التحكم
2. **Header جديد**: شعار في المنتصف فقط + زر "ابدأ الآن" يميناً (يحوّل إلى `/auth` أو ملف المستخدم).
3. **Footer موسّع** بأقسام: أفلام، مسلسلات، ريلز، مؤثرون، عن المنصة، الدعم، الباقات.

## المرحلة 2 — صفحات المحتوى (واجهة المستخدم)

4. **صفحة تفاصيل المنتج** `/title/:id` بأسلوب Apple TV+:
   - بانر سينمائي ضخم + تريلر/برومو قابل للتشغيل
   - ملخص، الفئة المستهدفة (أب/أم/ابن/ابنة)، التصنيف العمري، المدة، المسار
   - الحلقات/الأجزاء، الممثلون، إنتاج، شارات الجودة
   - أزرار: مشاهدة، إضافة للقائمة، مشاركة
   - "محتوى مشابه"
5. **صفحات أقسام**: `/movies`, `/series`, `/reels`, `/influencers` (شبكات محتوى مع فلاتر).
6. **صفحة المؤثرين الأذكياء** `/influencers/:id`:
   - شخصيات ذكاء اصطناعي (مثل "الشيخ هنا"، "العمّة سلمى"، "الكابتن طارق") تخاطب الأطفال
   - واجهة شات مخصّصة لكل شخصية + صوت/أفاتار
   - حدود محتوى آمنة للأطفال

## المرحلة 3 — المساعد التربوي الذكي (للأب/الأم)

7. مساعد شات تفاعلي عبر Lovable AI Gateway:
   - حوار طبيعي مع الأب/الأم لفهم احتياجات الأسرة
   - يولّد **طلبات محتوى** ويحفظها في جدول `content_requests`
   - يقترح من الكتالوج الموجود + يرسل ما هو غير متوفر لقسم الطلبات في لوحة التحكم

## المرحلة 4 — الباقات والدفع

8. **صفحة باقات** `/pricing` بثلاث باقات:
   - **الأسرة** (5 ملفات)
   - **الأصحاب** (3 ملفات)
   - **الأفراد** (ملف واحد)
   - حقل برومو كود + بانر عروض
9. **بوابة الدفع**: التوصية = **Paddle** (Merchant of Record، ضرائب وعالمي بدون إعدادات). إن أردت Stripe بدلها قل لي.
   - بعد تفعيلها، أربط المنتجات وأنشئ Checkout + Webhook + جدول `subscriptions`
   - في لوحة التحكم: قسم لإدارة الباقات والأكواد ولاحقاً تفعيل/تعطيل بوابات إضافية.

## المرحلة 5 — صفحة الدعم الجماهيري والتمويل

10. صفحة `/support` كأنها موقع مستقل:
    - رسالة المؤسس، رؤية المشروع، مستويات الدعم (راعٍ ذهبي/فضي/داعم)
    - شريط تقدّم الهدف، شهادات، تواصل
    - زر تبرّع مربوط بنفس بوابة الدفع.

## المرحلة 6 — لوحة تحكم "هنا" (Admin)

11. مسار `/admin` محميّ بـ `has_role(admin)`:
    - **نظرة عامة**: مستخدمون نشطون، اشتراكات، إيرادات، أكثر المسارات مشاهدة
    - **المحتوى**: CRUD لأفلام/مسلسلات/ريلز/مؤثرين + رفع صور وتريلرات
    - **الطلبات الجماهيرية**: عرض جميع طلبات المساعد الذكي مع:
      - تصفية حسب المسار/الفئة/الدور الأسري
      - تجميع تلقائي (clustering) للطلبات المتشابهة عبر AI
      - **ملخص مجمل** + **ملخص تفصيلي إحصائي** يوضّح مزاج الجمهور
    - **المستخدمون والأسر**: إدارة الأدوار والاشتراكات
    - **الباقات والمدفوعات**: إدارة الباقات، أكواد الخصم، سجل المدفوعات، تفعيل بوابات إضافية
    - **الدعم الجماهيري**: إدارة حملات التمويل والداعمين
    - **المؤثرون الأذكياء**: إدارة شخصياتهم وقواعدهم

## التفاصيل التقنية (مختصرة)

- **Backend**: Lovable Cloud (Supabase) — جداول: `profiles`, `user_roles`, `titles`, `episodes`, `reels`, `influencers`, `content_requests`, `subscriptions`, `plans`, `promo_codes`, `donations`, `assistant_conversations`.
- **AI**: Lovable AI Gateway (Gemini Flash) — للمساعد التربوي، شخصيات المؤثرين، تجميع وتلخيص الطلبات.
- **Payments**: Paddle عبر `enable_paddle_payments` (افتراضي) أو Stripe إن طلبت.
- **Routing**: React Router مع protected routes (`/admin`, `/account`, `/title/:id` ...).
- **Realtime**: لتحديث طلبات الجمهور والمدفوعات في لوحة التحكم لحظياً.

## أسئلة قبل أن أبدأ

1. **بوابة الدفع**: أبدأ بـ **Paddle** (الأنسب لمحتوى رقمي عالمي ويتولّى الضرائب)، أم تفضّل **Stripe**؟
2. **نقطة الانطلاق**: هل أنفّذ كل المراحل تباعاً في جلسات متتالية، أم تريدني الآن أبدأ بـ **المرحلة 1 + 2** فقط (الأساس + الهيدر/الفوتر + صفحة المنتج) لنرى الشكل ثم نكمل؟
3. **المؤثرون الأذكياء**: هل لديك أسماء/شخصيات محددة، أم أقترح أنا 4 شخصيات (شيخ، أم حنونة، كابتن مغامر، عالِمة فضول)؟
4. **محتوى وهمي**: هل أضع بيانات تجريبية (أفلام/مسلسلات وهمية بصور مولّدة) للعرض، أم تنتظر حتى تُدخل أنت المحتوى الحقيقي من لوحة التحكم؟
